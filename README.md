# USG IPv6 Statistics

## Project with goal of measuring the deployment and utilization of IPv6 vs IPv4 over time. 

## Overall

Measure all time deployment of IPv4 and IPv6 prefixes for USG related ASNs. Consider all options for reading network deployment data, focusing on RouteViews as a source for route tables.  


## Since 2020

Measure all time deployment of IPv4 and IPv6 prefixes for USG related ASNs since OMB mandate in 2020.
